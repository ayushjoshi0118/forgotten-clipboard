Privacy & Security Notice

100% Local & Private

Forgotten Clipboard was built from the ground up with a strict privacy-first architecture:

  • Zero Cloud Sync: All clipboard records reside entirely in your browser's private chrome.storage.local sandbox.
  • Zero Telemetry: No analytics, tracking beacons, ads, or external network requests of any kind are included.
  • User-Initiated Capture: In compliance with Chrome Manifest V3 security rules, clipboard reading occurs strictly upon explicit user interaction (clicking "Capture Clipboard", pasting text, or right-clicking to save selection). The extension never performs background clipboard snooping.
  • Safe Text Rendering: Saved snippets are rendered safely using strict DOM text nodes (textContent) to prevent script injection and XSS vulnerabilities.
  • Sensitive Data Warning: Clipboards can occasionally contain sensitive information like passwords, API keys, or private notes. You can delete individual items or clear your entire history at any time.
